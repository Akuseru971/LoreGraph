# LoreGraph — 173 Champion Tier A Audit

**Baseline:** production commit `17c8b42f6e5eda324b547df86cee3b8c5e290cbf`

## Executive summary

- Champions audited: **173**
- Phase 1 profiles requiring Tier-A revalidation: **15**
- Curated profiles with provenance/continuity gaps: **45**
- Minimal roster-expansion profiles requiring a full Tier-A build: **113**

The primary bottleneck is no longer roster coverage. It is evidence quality. A champion should reach Tier A only when the chain **public sentence → atomic claim → exact source** is intact and its core timeline/relationships are trusted.

## Recommended Tier A gate

- Content completeness ≥ 85
- Source coverage ≥ 80
- Canon confidence ≥ 85
- Review coverage ≥ 90
- Trusted timeline coverage ≥ 70%, with **no provisional CORE beat**
- Direct-relationship review coverage ≥ 80% when direct relationships exist
- Continuity classified
- No unresolved direct relationship, unsupported PARTICIPANT edge, or P0/P1 canon red flag

## Minimum content bundle for a real Tier A profile

1. **Biography:** 3–5 original bioBlocks, each classified FACT / SUPPORTED_SYNTHESIS / EDITORIAL_FRAMING and backed at claim level.
2. **Claims:** normally 5–10 atomic claims covering identity, origin, transformation, major conflict, current state and direct relationships.
3. **Timeline:** 3–5 meaningful beats. Trusted beats require `FACT + VERIFIED_CANON + claimIds + sourceIds`.
4. **Relationships:** direct edges only when interaction/kinship is explicit; shared region/faction/history stays structural.
5. **Events:** every link has an EventRelationRole. `PARTICIPANT` requires exact evidence.
6. **Continuity:** MAIN_RUNETERRA / ARCANE / LEGACY / other must be explicit where relevant.
7. **Sources:** current Riot champion bio first; add Riot stories/comics/cinematics/game narrative when the claim needs them.
